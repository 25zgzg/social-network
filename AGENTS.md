# AGENTS.md — social-network

## Граф проєкту (graphify)

У проєкті є мапа коду — knowledge graph у `graphify-out/` (граф, згенерований `graphify . --code-only`).

### Як користуватись графом

- **Зосереджені питання** (що пов'язано з чим, чому щось існує): спочатку `graphify query "<запитання>"` — дає сконопований підграф, значно менший за читання сирих файлів. `graphify explain "<символ/клас>"` — пояснення конкретного вузла. `graphify path "<A>" "<B>"` — шлях між двома символами.
- **Широкий архітектурний контекст**: читати `graphify-out/GRAPH_REPORT.md` (god nodes, спільноти, запропоновані питання).
- **Не читати сирі файли напряму**, якщо на запитання можна відповісти через граф. Якщо граф неоднозначний (наприклад `explain "Profile"` дає 2 вузли) — уточнити повним node id або шляхом файла, тоді читати сам файл.
- **Нагадування**: плагін `.opencode/plugins/graphify.js` сам підказує використовувати граф перед bash-командами.

### Оновлення графа

- Після змін у коді: `graphify update .` (AST, без API-ключа, безкоштовно).
- Список виключень — `.graphifyignore`.
- Git hook (`graphify hook install`) сам перебудовує граф після кожного коміту.

### Обмеження поточної збірки

- Граф побудовано в режимі `--code-only` (тільки Python-код через tree-sitter AST, без LLM-екстракції документів). 23 `.md`-файли не індексовані.
- LLM-прохід (документи, `--mode deep`, автоматичні назви спільнот у GRAPH_REPORT.md) потребує API-ключ (ANTHROPIC_API_KEY / OPENAI_API_KEY / GEMINI_API_KEY тощо). Зараз не налаштований.
